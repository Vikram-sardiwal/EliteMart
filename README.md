\# 🛍️ EliteMart — Full Stack MERN E-Commerce Website



EliteMart is a full-stack e-commerce web application built using the MERN stack. It provides a complete online shopping experience with authentication, product browsing, cart, wishlist, checkout, orders, reviews, admin product management, and an AI chatbot.

\## ✨ Features



\### 👤 User Features



\- User Registration and Login

\- JWT-based Authentication

\- Secure authentication using HTTP cookies

\- Browse products

\- Search products

\- Filter products by:

&#x20; - Gender

&#x20; - Category

\- Product details page

\- Add products to cart

\- Update cart quantity

\- Remove products from cart

\- Wishlist functionality

\- Checkout

\- Address management during checkout

\- Cash on Delivery

\- Razorpay payment integration

\- Place orders

\- View order history

\- View individual order details

\- Product reviews and ratings

\- User profile

\- Responsive design

\- AI-powered shopping chatbot



\### 🛠️ Admin Features



\- Admin authentication

\- Admin dashboard

\- Add new products

\- Upload product images

\- Edit products

\- Manage products

\- Update product information

\- Manage product stock

\- Manage product categories and gender

\- Product activation/deactivation



\---



\## 🤖 AI Shopping Assistant



EliteMart also includes an AI chatbot designed to help users with their shopping experience.



The chatbot can be used as a conversational shopping assistant and is integrated with the backend API.



> AI API credentials are stored in environment variables and are not included in this repository.
